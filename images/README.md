## การเปลี่ยนรูปภาพ:

หากต้องการใช้รูปภาพจริงของบริษัท:

1. วางรูปภาพในโฟลเดอร์ `images/`
2. เปลี่ยน URL ใน `index.html` จาก Unsplash เป็น `images/filename.jpg`
3. ตรวจสอบขนาดและความคมชัดของรูปภาพ

## ข้อควรระวัง:

- รูปภาพควรมีขนาดไม่เกิน 2MB
- ใช้รูปแบบ .jpg หรือ .png
- ควรมี alt text สำหรับ SEO
- รองรับการทำงานบน mobile และ desktop
